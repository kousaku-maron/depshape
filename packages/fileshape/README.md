# fileshape

git の差分を、**変更された各ファイルの行の差分** としてブラウザに見せる、[diffshape](../diffshape) のモジュールです（左のアイコンバーの「ファイル」）。
GitHub の Files changed と同じ見え方で、依存（[depshape](../depshape)）や DB（[dbshape](../dbshape)）の形と同じ画面・同じコメントの流れで読めます。

## 使い方

解析したいリポジトリの中で実行します（Node.js 20 以上と git が必要です）。

```bash
npx @kousaku-maron/diffshape . main --merge-base
```

ファイルの差分だけを開くなら、同じパッケージに入っている `fileshape` コマンドを使います（`npm install -g @kousaku-maron/diffshape` で入ります）。比較の指定は `diffshape` と同じです。

| コマンド | 比較内容 |
|---|---|
| `fileshape` | 未コミットの変更すべて vs HEAD（未追跡のファイルも含みます） |
| `fileshape . main --merge-base` | 現在の作業ディレクトリ vs main からの分岐点（GitHub の PR と同じ見え方） |
| `fileshape abc1234` | そのコミット単体の変更 |
| `fileshape staged` / `fileshape working` | ステージ済み / 未ステージの変更のみ |

オプション: `--port <n>`、`--host`、`--no-open`、`--clean`（この比較のレビューコメントと確認済みのマークを消してから開く）、`--json`（`fileshape` のみ。差分を JSON で標準出力へ）

## 画面

- **左のファイルツリー**: 変更されたファイルをフォルダごとに並べます（子が1つだけのフォルダは `src/app` のように1行にまとめます）。クリックでそのファイルへ移動し、読んでいるファイルが光ります。上の欄でパスを絞り込めます
  - **変更 / 全体**: 「全体」にすると、変更していないファイルも含めたリポジトリのすべてのファイルを並べます（最初は変更のあるフォルダだけ開いています）。変更していないファイルをクリックすると、右の一覧のツリーの順番の位置に、その中身が「変更なし」として加わります。行番号もコメントも差分と同じように使え、見出しの「閉じる」で一覧から外せます。開いたファイルは比較ごとにブラウザに保存し、コメントを書いたファイルはコメントがある間は一覧に残ります
- **Unified / Split**: 1列（`git diff` と同じ）か、左右に変更前・変更後を並べるかを切り替えます。選んだほうを覚えておきます
- **シンタックスハイライト**: 拡張子から言語を選びます（TypeScript / JavaScript / Go / Python / Rust / SQL / YAML など）。とても大きなファイルは色を付けずに表示します
- **前後の行の展開**: hunk の見出しの ↑ ↓ で、git が省いた前後の行を 20 行ずつ開きます（⇕ / ↕ ですべて）。ファイルの最後の残りも開けます
- **単語単位の差分**: 変更された行の中で、変わった単語に濃い色を付けます（行がほとんど別物のときは付けません）
- **プレビュー**: Markdown は「差分 / プレビュー」を切り替えられます（Split では変更前と変更後を並べます。表やチェックリストにも対応し、リポジトリ内の画像は同じ側のものを表示します。ファイル内の HTML はそのまま描きません）。画像は変更前と変更後を並べて、サイズと一緒に表示します
- **確認済み**: ファイルの見出しかツリーのチェックで付けます。付けたファイルは折りたたみ、上に進み具合を出します。そのファイルの変更がまた変わると外れます
- **折りたたみ**: ロックファイルやビルド結果などの生成ファイル（`.gitattributes` の `linguist-generated` も見ます）と、とても大きな差分は、最初から折りたたんでいます
- **行コメント**: 行番号をクリックすると、その行にコメントを書けます。行番号をドラッグするか Shift+クリックすると、複数行への範囲コメントになります。開いた前後の行にも書けます。「AI 用にコピー」では difit と同じく `path:L12` / `path:L12-L15`（変更前の行は `(old)` つき）とコメント本文を `=====` で区切って並べます。行番号はコピーするときの位置です。AI がファイルを書き換えたあとに再読み込みすると、行がずれていても同じコードの行についていき、コードが変わったら「コメント後に変更あり」、行が差分からなくなったら「解消済み？」になります

コメントと確認済みの印は、リポジトリと比較ごとにブラウザに保存します。
